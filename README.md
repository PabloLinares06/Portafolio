## 🌟 Características de la Experiencia

* **Command Palette Global (`⌘K` / `Ctrl+K`):** Menú flotante ultra-rápido para saltar a secciones, explorar casos de estudio, copiar email con feedback de confetti y alternar sonido.
* **Sintetizador Procedural de Audio (Web Audio API):** Retroalimentación acústica háptica en hover, clic, apertura de consola y éxito, con cero archivos de audio externos (0 kB de descarga) y control de silenciado sincronizado con `localStorage`.
* **Consola Dev Interactiva (`>_ Terminal`):** Terminal flotante con prompt Unix interactivo, comandos (`whoami`, `projects`, `natec`, `fuelix`, `stack`, `contact`, `sudo hire`) y easter eggs.
* **Topología Interactiva de Arquitectura:** Diagrama interactivo de flujo de datos por etapas en cada caso de estudio, desglosando protocolos, latencias y responsabilidades de componentes.
* **Casos de Estudio de Alto Impacto:**
  1. **VitalAPP:** Backend empresarial en .NET 9, C#, Dapper, MediatR CQRS, SQL Server y React 19.
  2. **NaTec V2:** E-Commerce mayorista con integración oficial a EFFI ERP, modo kiosko táctil con PIN, motor gráfico Canvas 2D y migración crítica de Firebase a VPS DigitalOcean con Docker Compose.
  3. **Fuelix:** Plataforma SaaS para Estaciones de Servicio (EDS) con nodos Edge en Raspberry Pi (lectura serial a dispensadores) y arquitectura offline-first.

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la experiencia.
